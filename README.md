# Refrigerator Management System

A simple Java Console Application that manages an inventory of refrigerators. The project demonstrates fundamental Object-Oriented Programming (OOP) concepts such as encapsulation, data processing, sorting routines, array manipulations, and dynamic matrix structures.

## Features

1. **Interactive Data Input**: Read an array of refrigerators dynamically from the CLI.
2. **Comprehensive Search**: Query objects using multi-conditional checks (e.g., Brand and Maximum Price threshold).
3. **Filtering**: Extract items matching criteria like Energy Efficiency classes.
4. **Inventory Deletion**: Dynamically resize data structures upon criteria deletion.
5. **Sorting Capabilities**: Implements an ascending Bubble Sort based on net capacity volume.
6. **Matrix Transformation**: Maps elements onto a quadratic matrix diagonal configuration.
