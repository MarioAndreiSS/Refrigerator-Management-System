# Refrigerator Management System

A simple Java console application for managing a refrigerator inventory. 
The project demonstrates fundamental Object-Oriented Programming (OOP) concepts 
such as encapsulation, sorting algorithms, array manipulation, and matrix transformations.

## Features

1. **Interactive Data Input** – Dynamically reads refrigerator data from the command line.
2. **Comprehensive Search** – Searches refrigerators using multiple conditions (e.g., brand and maximum price).
3. **Filtering** – Filters refrigerators by energy efficiency class.
4. **Inventory Deletion** – Removes items dynamically and resizes the data structure.
5. **Sorting Capabilities** – Implements Bubble Sort in ascending order based on net capacity.
6. **Matrix Transformation** – Maps refrigerator data onto a square matrix diagonal structure.
